# Примеры курса «Автоматизация маркетинга и продаж»

Форма принимает регистрации на встречу и передаёт их в ваш n8n. Участник может оставить почту для регистрации и отказаться от рассылки. Обе регистрации попадают в таблицу, по которой организатор считает заявки из рекламной кампании.

## Как запустить форму

1. Запустите [свой n8n](../README.md). В проекте, где будет процесс, откройте вкладку **Data tables** и создайте таблицу с именем `registrations`. Добавьте пять столбцов типа **String** с именами `registrationId`, `registeredAt`, `email`, `source` и `campaignId`. Для `marketingConsent` выберите тип **Boolean**.
2. Создайте процесс в том же проекте. В меню **Import from File** выберите [registration.json](registration.json) и нажмите **Publish**. Нода «Сохранить регистрацию» находит таблицу по имени. Нода «Ответ форме» возвращает номер сохранённой регистрации. После неё можно добавить проверку согласия на рассылку.
3. Откройте каталог _marketing-sales_ в терминале и выполните `python3 server.py`. Для локального n8n подходит адрес вебхука по умолчанию. Если n8n работает в облаке, перед запуском задайте переменной окружения `N8N_WEBHOOK_BASE` адрес вашего n8n с окончанием `/webhook`.
4. Откройте [форму регистрации](http://127.0.0.1:8001/?campaignId=42). Число `42` в адресе можно заменить идентификатором своей кампании. Введите учебную почту, выберите, хотите ли получать материалы, и отправьте форму. Скопируйте номер со страницы подтверждения и найдите строку с этим номером в таблице `registrations`.

Форма передаёт идентификатор кампании строкой. При переходе без метки значение `campaignId` пустое. Поле `source` содержит `event-site`, а `registeredAt` хранит время отправки в UTC. Чтобы посмотреть, какие данные получил n8n, откройте выполнение процесса во вкладке **Executions**.

## Файлы для уроков

- Таблица [subscribers.csv](subscribers.csv) содержит три записи организатора с согласием на рассылку и направлением встречи. Перед работой с Unisender замените адреса в копии файла своими тестовыми адресами.
- Отчёт [direct-costs.tsv](direct-costs.tsv) содержит расходы для проверки расчёта по кампаниям.
- Файлы [site-request.json](site-request.json) и [partner-requests.csv](partner-requests.csv) описывают два обращения Анны Соколовой. Сайт и партнёр присвоили разным обращениям один номер.
- Выгрузка [pipeline-events.json](pipeline-events.json) содержит события для проверки отчёта о первом переходе сделки на подготовку предложения.
