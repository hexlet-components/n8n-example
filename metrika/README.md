# Примеры курса «Автоматизация с Яндекс Метрикой»

Школа принимает заявки на консультацию. На втором сайте посетитель регистрируется на мероприятие. Для обоих сайтов нужны Python 3 и свой счётчик Метрики. В формах используются только учебные данные.

1. Клонируйте репозиторий командой `git clone https://github.com/hexlet-components/n8n-example.git`. Если копия уже есть, обновите её командой `git pull`.
2. Запустите n8n по [инструкции проекта](../README.md). В редакторе создайте два процесса. В меню каждого выберите *Import from File* и загрузите по одному файлу из этого каталога. Файл *application.json* принимает заявку, а *processed.json* получает запись при смене статуса. Опубликуйте оба процесса. Для просмотра входных данных в истории включите сохранение успешных производственных выполнений в настройках процессов.
3. Перейдите в каталог примеров командой `cd n8n-example/metrika` и запустите `python3 server.py`. По умолчанию сервер обращается к рабочим вебхукам своего n8n на порту 5678. Для облачной установки перед запуском задайте переменную окружения `N8N_WEBHOOK_BASE` с адресом вида `https://ваш-домен/webhook`.
4. Откройте <http://localhost:8000/school/index.html>. Отправьте форму. Сервер передаст заявку в n8n, сохранит её в локальной базе и покажет страницу *thanks.html*. На странице *form.html* та же форма показывает номер заявки без перехода. При учебном отказе обычная форма снова открывает страницу записи, а запрос со страницы *form.html* получает ответ 422. Второй сайт открывается по адресу <http://localhost:8000/event/index.html>.
5. Чтобы взять заявку в работу или отметить посещение мероприятия, скопируйте номер из терминала сервера и в другом терминале из того же каталога выполните `python3 server.py --process НОМЕР`. В n8n откройте последнее выполнение процесса «Обработка заявки». В выходе ноды «Запись заявки» появятся данные первоначальной заявки и время смены статуса `processed_at` в секундах Unix.

Код счётчика добавляется отдельно в *school/counter.js* и *event/counter.js*. Обработчик формы без перехода находится в *form.js* соответствующего сайта. Изменения становятся видны после обновления страницы. База хранится в домашнем каталоге в файле *.hexlet-metrika.sqlite*. Если передача статуса оборвалась, сверьте последнее выполнение в n8n перед повтором команды. Повтор использует сохранённое время обработки.
